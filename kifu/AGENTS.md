# kifu パッケージ

KIF 形式（将棋の棋譜テキスト）の読み書きと、棋譜まわりの表記変換。I/O を含まない純粋関数のみ。
利用側は kicho（棋譜の取得・保存）と ikkyoku（読み筋の表示・棋譜の貼り付け・盤面図の登録）。
**理由・経緯・実際に踏んだ不具合はコードのコメントに書いてある。** ここには要点と置き場所だけを置く。

| ファイル | 中身 |
|---|---|
| `kifu.go` | 指し手行（`FormatLine`）・終局判定（`TerminalMarkers`）・消費時間・`Document.String()` |
| `parse.go` | KIF テキスト → `Document`（`Parse`） |
| `bod.go` | 盤面図（途中の局面から始まる棋譜。`FormatBOD` / `ParseBOD` / `HasBOD`） |
| `decode.go` | KIF の指し手 → USI（`Decoder` / `DecodeMoves`）と手合割 → SFEN（`StartSFEN`）。**盤は要らない** |
| `csa.go` | CSA の指し手 → USI（`DecodeCSA`）。**盤が要る**（成ったのか元から成駒か） |
| `notation.go` / `board.go` | USI の手 → 日本語表記（`NewNotation` / `FormatMoves`）。**盤全体が要る**ので `usi` ではなくここ |

## 全体に効くこと

- **合法性は見ない**（decode / csa / notation のどれも）。指せるかは合法手生成を持つ層の問題
- **読めない手が出ても、そこまでの結果は返す**（`DecodeMoves` / `DecodeCSA` / `FormatMoves`）
- **ただし別の局面として読めてしまう誤りはエラー**：知らない手合割・読めない盤面図・
  知らない CSA の `%` 表記・CSA の符号と手番の食い違い。**平手や手合割へ黙って倒さない**
- **書くときは 1 通り、読むときは方言を広く受ける**（成駒の略記 杏/圭/全、`(00)` の打ち、
  上手／下手、`竜`/`王`、算用数字、半角区切り）
- **内部座標 (x,y) は 1..9 で、y=1 が上（後手陣）**。`sfen` の (rank,file) とは別物（`board.go`）

## 崩さないこと

- **`Parse` は指し手 0 手でもエラーにしない**（対局前の中継）。「KIF ではない」は `Document.Empty()` で判定
- **`Parse(d.String())` で元に戻る**（テストで固定。終局の `投了打` だけ `投了` に正規化）
- **変化（`変化：N手`）は未対応**で、そこで打ち切る。分岐を扱うなら `Document` に木が要る
- **`#` 行はコメントではない。** コメント（`*`）は注釈する手の**直後**
- **消費時間は `ShowTime` があるときだけ出す**（0 秒の手は正当なので値では判定できない）
- **終局の `投了打` を打ち手と誤判定しない。** 逆に `５三銀打` を終局と誤判定しない（`TerminalMarker`）
- **盤面図は 1 マス 2 文字**（成駒は 1 文字の と杏圭全馬龍）。**盤面図があるなら手合割は書かない**。
  手番の行は後手番のときだけ。手数は書けないので 1 を返す（推測しない）。駒台の玉は落ちる
- **"不成" を先に見る。** 末尾の "成" は必ず「成った」
- **駒落ちは上手（後手）が初手**なので `StartSFEN` は `w`
- **CSA の `%+ILLEGAL_ACTION` / `%-ILLEGAL_ACTION` は入れていない**（勝敗の向きを手番で書き分ける必要がある）
- **日本語表記は状態を持つ**（読み筋 1 本につき 1 つ）。**最初の 1 手は「同」にしない**。
  **打ちには必ず「打」**（`FormatLine` が `(00)` を決めるのに使う）。左右は指した側の視点で、
  修飾は**向きの値で比べる**（ラベルで比べない）

## JS 側（`web/`）との分担

ルートの `AGENTS.md`「Go と JS の 2 ソース」の対象は次の 2 つだけ。**片方だけ直さない。**

- 指し手行の書式（`FormatLine` / `TerminalMarker`）↔ `web/kifu.js`
- CSA の成り判定（元が生駒で CSA が成駒のときだけ `+`）↔ `web/csa.js`（`csaToUsi` / `usiToCsa`。1 手ずつ・盤は呼び出し側）

`Document`（ヘッダ・コメント・盤面図）・`Parse`・KIF → USI・日本語表記は Go 側だけ（揃える対象外）。
