# 将棋フォントツール

将棋の駒をSVGで表現しようとしているのですが、駒をSVGのテキストで表示する予定です。

```
歩、香、桂、銀、金、角、飛、王、と、杏、圭、全、馬、龍
```

この文字の為に日本語のフォントを利用するのは重いので、これらのフォントのデータを抜き出して、軽量化を行おうと思っています。
またシステムとしては漢字ではなく、SFENと呼ばれる形式で表現したい為、

```
P,L,N,S,G,B,R,K,+P,+L,+N,+S,+B,+R
p,l,n,s,g,b,r,k,+p,+l,+n,+s,+b,+r
```

文字にマッピングして表示を行いたい。(後手の表現は小文字で行われる)
後手(小文字)だからといってフォントで文字の反転は行う予定はありません。

ようは

```
<text>P</text>
```

と行うと歩が表示される感じです。

## アーキテクト

Go言語で作成し、

```
shogi_font.go {inputfont}
```

で新しいフォントを出力する
