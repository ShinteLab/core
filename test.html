Shogi SFEN フォントテスト

先に go run . {入力フォント} で shogi.ttf を生成しておくこと（リポジトリには含めていない）。

基本駒 (先手 = 大文字 / 後手 = 小文字)

P L N S G B R K
p l n s g b r k

成駒 (リガチャ: + と組み合わせ)

+P +L +N +S +B +R
+p +l +n +s +b +r

異体字・反転字（1）stylistic set で切り替える

本文は SFEN のまま（K / +B）で、CSS の font-feature-settings で字だけが変わる。ブラウザの HTML/SVG 専用。

CSS本文表示
（なし）K +BK +B
"ss01"K +BK +B
"ss02"K +BK +B
"ss01", "ss02"K +BK +B

⚠️ font-feature-settings は個別の値が積み上がらず、後から当てた宣言が丸ごと勝つ。 両方効かせるには 1 つの宣言にまとめること。

異体字・反転字（2）文字で選ぶ

本文の文字自体を変える。Canvas 2D や Go 側の画像生成でも同じように出る （そちらは GSUB を解釈しないので stylistic set が効かない）。

出したい字描く文字表示
王（既定）K / k / 王K
玉玉 (U+7389)玉
馬（成角）+B / 馬+B
左馬&#xE000;（私用領域）

左馬は「馬」を左右反転したもの。並べて確認 → 馬
U+E000 はこのフォントが勝手に決めた符号位置なので、駒フォントを当てていない要素では別の字（または豆腐）になる: 

SVG での利用例

期待表示: 歩 香 桂 銀 金 角 飛 王 / 成駒は と 杏 圭 全 馬 龍 / 異体字は 玉 と 左馬（馬の鏡像）
